Neogalleries is a simple, free and open source gallery CMS for Neocities!

Get Neogalleries

You can download the Neogalleries Template from the official repository on GitHub.

It's a very basic website, that only includes the essential features for a gallery.

How to use

After building and publishing your website in Neocities, you can manage your gallery from this very admin panel. No need to fork this panel into your site

You can place a link to the admin panel in your website's navigation to make things a little bit easier:

<a onclick="NeoGalleries.openAdminWindow()" class="fg-link">NeoGalleries Admin</a>
